# PROJECT: DigiiState OS

## Business Context
- **Company**: DigiiState
- **Product Name**: DigiiState OS (Hub)
- **Target Customer**: Operators & Management
- **Business Model**: Integrated Venture Hub
- **Product Purpose**: Centralized operating system for managing DigiiState's portfolio, domains, and core metrics.

## Product Structure
- **Pages**:
  - `/`: Main dashboard / Hub
  - `/governance`: Corporate policies
  - `/tos`: Terms of Service
  - `/privacy`: Privacy Policy
- **User Roles**:
  - **Operator**: Access to production metrics and configurations.
- **Major Workflows**:
  - Portfolio monitoring
  - Domain management
  - Lead routing tracking
  - Ranking analysis (Quad-Pulse)

## Technical Architecture
- **Frontend**: Astro.js, Tailwind CSS ("Bloomberg" Aesthetic)
- **Backend**: Supabase (Live sync pending)
- **Infrastructure**: Cloudflare Pages
- **Integrations**: Make.com (Leads), Twilio (Voice), Serper.dev (Rankings)
